# ISTe Discord: голосовая активность, жалобы, статусы комнат

## Границы
Категории: CYBERION Kalynova, CYBERION Zavodskaya. Учитывать только реальные входы пользователей в голосовые каналы этих категорий. Не считать mute/deafen события как новые сессии, не считать ботов. Функции запускаются после проверки настроек и авторизации сервера.

## Рейтинг активности
Gateway получает VoiceStateUpdate. При входе создаётся активная сессия, при выходе закрывается. Переход между каналами одной категории закрывает старую сессию и открывает новую. Между категориями подсчёт разделён. Если пользователь покинул сервер или worker перезапустился, провести сверку активных сессий с Discord Gateway и закрыть потерянные сессии без начисления времени простоя. Не начислять дважды при повторных событиях. Точки агрегации: за день, неделю, месяц, всё время; время в секундах, отображение в часах и минутах. Таблица лидеров /voice-top и необязательная периодическая публикация по выбору администратора. Не раскрывать приватные названия скрытых комнат в публичном рейтинге.

## Жалобы
/complaint (target, reason, evidence_url optional), кнопка «Пожаловаться» с модальной формой. Подтверждение автору только приватным ответом. Проверять отсутствие саможалобы, длину причины и ссылку доказательства, ограничивать частоту повторной отправки. Жалобы и доказательства доступны только уполномоченным модераторам. Кнопки «Взять», «Решить», «Отклонить» должны проверять полномочия на сервере перед изменением состояния. Сохранять ID модератора и временные метки. Никаких автоматических банов по жалобам, без публикации обвинений в открытые каналы.

## Статусы войсов
Для владельца приватной комнаты меню: Играем FACEIT, Ищем +1, Тренировка, Не беспокоить, Отдыхаем, Очистить. Статус сохранять по channel_id, проверять владельца на сервере и показывать через Discord voice channel status, если endpoint и права поддерживаются; иначе краткий суффикс названия с соблюдением длины 100 символов. Значки 🔒 и 🔓 сохранять при смене статуса, смене имени и закрытии. Удалять запись статуса вместе с комнатой.

## Проверки перед выпуском
Тесты: два разных входа создают комнаты в правильных категориях; не видны лишние приватные каналы; сессия не дублируется; переход между категориями закрывает старую и открывает новую; перезапуск без накрутки статистики; жалоба не раскрывается обычному пользователю; только модератор меняет её статус; только владелец управляет статусом комнаты; статус не ломает замок и переименование; удалённая комната очищает состояние. Отдельно проверить права бота, ограничения Discord API и готовность миграции.

Эта документация описывает план, а не уже работающий функционал.
