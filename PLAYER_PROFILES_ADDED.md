# Страница профилей игроков

Кнопка «СОСТАВ» на главной странице теперь открывает отдельную страницу команды.

Страница получает актуальный состав из FACEIT, исключает игрока Kortavyj и показывает остальных игроков в статичном фирменном дизайне ISTe.

Для каждой игровой роли подготовлено собственное описание и набор сильных сторон. Никнеймы, аватары, страны, уровни и ссылки на FACEIT продолжают обновляться через существующий GitHub Actions workflow.
