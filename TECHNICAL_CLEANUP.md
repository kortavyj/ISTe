# Техническая очистка проекта

В проекте удалено повторное подключение Navbar.

Компонент Intro оставлен в одном экземпляре. Таймеры корректно очищаются при размонтировании, а заставка не повторяется при возврате на главную внутри одной сессии сайта.

Стили разделены по компонентам. В App.css остались только общие стили приложения, страниц и секций.

Navbar переведён на NavLink. Активный раздел определяется автоматически.

Кнопки главного экрана теперь прокручивают страницу к составу и матчам.

Удалены неиспользуемые Tailwind CSS, Framer Motion, React Icons, шаблонные изображения и пустые файлы.

Добавлена отдельная страница для неизвестных адресов.

Добавлены базовые метаданные страницы, семантическая разметка, подписи навигации, адаптивность и поддержка prefers reduced motion.

Проверены синтаксис всех JavaScript и JSX файлов, существование локальных импортов и баланс CSS блоков.
