# Командные матчи ISTe

Кнопка «МАТЧИ» на главной странице открывает маршрут `#/matches`.

Список формируется только из турниров команды ISTe в FACEIT. История отдельных игроков не используется.

При ручном запуске workflow `Update FACEIT statistics` включена полная синхронизация. Она проходит по всем турнирам команды и собирает все доступные матчи. Запуски по расписанию обновляют активные и последние турниры, сохраняя уже найденную историю. Это уменьшает количество запросов к FACEIT.

На странице есть фильтры для всех, предстоящих и завершённых матчей. Каждая карточка открывает соответствующую комнату FACEIT. На главной странице показывается текущий матч, ближайший матч или последний завершённый матч.

После загрузки проекта в GitHub открой `Actions`, выбери `Update FACEIT statistics`, нажми `Run workflow` и оставь включённым параметр полной синхронизации.
