# Старт главной страницы с блока состава

После завершения стартовой анимации главная страница автоматически показывает блок «Состав команды».

Пользователь не запирается в этом блоке. Он может сразу прокрутить страницу вверх к главному экрану или вниз к матчам и медиа.

Автоматическое позиционирование выполняется только один раз после полной загрузки сайта и только на главной странице. При переходах между разделами повторного принудительного скролла нет.
