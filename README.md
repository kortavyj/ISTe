# ISTe Website

Сайт киберспортивной команды ISTe на React и Vite.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run lint
npm run build
```

## Структура

`src/components/layout` содержит общие элементы интерфейса.

`src/components/home` содержит блоки главной страницы.

`src/pages` содержит страницы маршрутов.

`src/assets` содержит локальные изображения проекта.
