# Подключение ISTe к GitHub Pages и FACEIT

Сайт получает публичные данные команды ISTe из FACEIT Data API.

GitHub Actions проверяет данные каждые пять минут. Когда данные изменились, workflow обновляет `public/data/faceit-stats.json`, сохраняет изменение в репозитории, собирает React проект и сразу публикует новую версию на GitHub Pages.

Открытая страница дополнительно проверяет опубликованный JSON раз в минуту без перезагрузки браузера.

Это не обновление секунда в секунду. GitHub Actions поддерживает минимальный интервал пять минут, а запланированный запуск иногда может задержаться.

## Настройка

1. Создайте приложение в FACEIT Developer Portal.
2. Внутри приложения создайте Server side API key.
3. Создайте пустой публичный репозиторий GitHub с веткой `main`.
4. Загрузите в корень репозитория всё содержимое папки проекта, включая папку `.github`.
5. В репозитории откройте Settings, затем Secrets and variables, затем Actions.
6. Создайте Repository secret с именем `FACEIT_API_KEY`.
7. Вставьте FACEIT API key в значение секрета.
8. Откройте Settings, затем Pages.
9. В Source выберите GitHub Actions.
10. Откройте Actions, затем `Update FACEIT statistics`.
11. Нажмите Run workflow и оставьте `full_match_sync` включённым.
12. Дождитесь зелёного результата workflow.
13. Затем откройте `Deploy ISTe website to GitHub Pages` и убедитесь, что первая публикация тоже завершилась успешно.

Не добавляйте API key в исходный код, `.env`, JSON или README.

## Версии сборки

Проект использует проверенные опубликованные версии React 19.2.8, React Router DOM 7.18.1, Vite 8.1.5 и плагин React 6.0.4. Файл package lock будет создан автоматически при первом локальном запуске npm install.
